# Ahmad & Hawraa — Love Index ❤️

موقع رومانسي بالعربية: **مؤشر حب أحمد وحوراء** — عدّاد حب يزداد تلقائيًا كل يوم.

مبني بـ Next.js (App Router) + TypeScript + Tailwind CSS v4 + Motion + Lucide Icons.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بناء نسخة الإنتاج
npm start
```

## ✏️ أين أعدّل؟

| ماذا تريد أن تغيّر | الملف |
|---|---|
| الأسماء، **تاريخ بداية الحب**، المنطقة الزمنية، قيمة البداية والزيادة اليومية، رابط الموقع، ملف الموسيقى | `config/site.ts` |
| رسائل زر «اضغطي هنا يا حوراء» + نص نافذة المفاجأة | `data/messages.ts` |
| الأسباب المئة | `data/reasons.ts` |
| رسائل اليوم (365 رسالة) | `data/dailyMessages.ts` |
| الخط الزمني «حكايتنا الجميلة» (محتوى تجريبي حاليًا) | `data/timeline.ts` |
| الألوان | `app/globals.css` (قسم `@theme`) |

## 💗 كيف يعمل مؤشر الحب؟

```
مؤشر الحب = 1,000,000 + (عدد الأيام منذ البداية × 1,000)
```

- يُحسب من تاريخ اليوم بتوقيت `America/Toronto` وتاريخ البداية فقط — لا قاعدة بيانات.
- يرى كل الزوار القيمة نفسها، ولا ينخفض أبدًا، ولا يعود للصفر بعد التحديث.
- اليوم الجديد يبدأ عند منتصف الليل بتوقيت تورونتو (مع مراعاة التوقيت الصيفي).
- **رقم مميز:** عند الوصول إلى مضاعف 1,000,000 (مثل 2,000,000) يظهر تصميم ذهبي احتفالي لمدة 7 أيام.
  لمعاينته الآن افتح الرابط مع `?milestone=1`.

## 🎵 الموسيقى

ضع ملفًا مرخّصًا في `public/music/romantic.mp3` (مثلًا من Pixabay Music).
لا تبدأ إلا بعد ضغط الزر. لإخفاء الزر: اجعل `music.src` فارغًا في `config/site.ts`.

## 🚀 النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. استورده في [vercel.com/new](https://vercel.com/new) — لا يحتاج أي إعدادات إضافية.
3. أضف متغير البيئة `NEXT_PUBLIC_SITE_URL` برابط موقعك (مثل `https://ahmad-hawraa.vercel.app`) ليعمل رابط المشاركة وصورة Open Graph بشكل صحيح.

## ♿ الوصول والأداء

- يحترم إعداد «تقليل الحركة» في الجهاز (تتوقف الحركات والقلوب المتطايرة).
- الخلفية المتحركة بـ CSS فقط، وعدد القلوب المتطايرة محدود للحفاظ على سلاسة الهاتف.
- الصفحة مولّدة مسبقًا (Static) — تحميل سريع جدًا.
